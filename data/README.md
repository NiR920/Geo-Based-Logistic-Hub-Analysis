# Data

The project uses the Kaggle **Real World Logistic Data** dataset documented in [`../docs/data-source.md`](../docs/data-source.md).

Raw third-party data is intentionally not committed to this repository. Download it from the original Kaggle source when reproducing the analysis.

Keep local datasets outside version control. The repository `.gitignore` excludes common tabular-data formats and generated output files.
